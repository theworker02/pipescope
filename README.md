# pipescope

Pipe validation gates for scope inputs before they hit prod.

**Site:** https://theworker02.github.io/pipescope/

## Install / run

```bash
git clone https://github.com/theworker02/pipescope.git
cd pipescope
node src/cli.js
node --test
```
